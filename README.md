# Novamesh — сервер (у каждого пользователя свой профиль)

## Как это работает

Когда человек открывает мини-апп в Telegram, Telegram сам передаёт сайту подписанные данные
о нём (`initData`: Telegram ID, имя, юзернейм). Сайт отправляет их серверу с каждым запросом,
сервер проверяет подпись токеном вашего бота (подделать нельзя) и отдаёт **только данные этого
человека**: его профиль, балансы, сделки и транзакции. Если открыть сайт мимо Telegram —
показывается заглушка «Откройте через Telegram».

Деньги полностью на вашей стороне: сервер лишь меняет цифры в базе, когда **вы** подтверждаете
что-то в админ-панели. Реальные переводы вы делаете сами.

## Файлы

- `server.js` — API; `bot.js` — бот (кнопка «Открыть Novamesh»); `db.js` — хранилище (`data.json`)
- `telegramAuth.js` — проверка подписи Telegram
- `public/mini-app.html` — сайт для клиентов
- `public/admin.html` — ваша админ-панель (вход по паролю `ADMIN_SECRET`)

## Что настроить ДО запуска

1. В `public/mini-app.html` найдите блок `PAY_DETAILS` и впишите **свои** реквизиты для пополнения
   (карта и адреса кошельков). Сейчас там заглушки.
2. Скопируйте `.env.example` → `.env` и заполните:
   - `BOT_TOKEN` — токен бота от @BotFather
   - `ADMIN_SECRET` — длинный пароль для админки (20+ случайных символов)
   - `MINI_APP_URL` — итоговый адрес `https://ваш-домен/mini-app.html`

## Запуск на Railway (постоянно, 24/7)

1. Залейте папку на GitHub (новый репозиторий).
2. railway.app → New Project → Deploy from GitHub repo.
3. Вкладка Variables: добавьте `BOT_TOKEN`, `ADMIN_SECRET`, `MINI_APP_URL`.
4. Settings → Networking → Generate Domain — получите адрес `https://….up.railway.app`.
5. Подставьте его в `MINI_APP_URL` (`https://…up.railway.app/mini-app.html`) и перезапустите.
6. @BotFather → ваш бот → Bot Settings → Menu Button → вставьте ту же ссылку.
7. ВАЖНО: добавьте в Railway Volume (постоянный диск) и смонтируйте его в папку проекта —
   иначе `data.json` может сбрасываться при перезапуске/новом деплое.

Админка: `https://ваш-адрес/admin.html`.

## Как вы работаете с админкой

- Заявки: пополнение — получили деньги, жмёте «Зачислить на баланс». Вывод / обмен на карту —
  сначала переводите человеку деньги, потом жмёте «Отметить выплаченным» (тогда списывается баланс).
- Сделки: кнопка двигает сделку по шагам Создана → Покупатель → Оплачена (вы подтверждаете оплату)
  → В эскроу → Получена. На последнем шаге сумма зачисляется продавцу, растёт торговый оборот.
- Пользователи: видите всех, кто заходил, и можете вручную поправить любой баланс.

## Безопасность

- Никому не показывайте `BOT_TOKEN` и `ADMIN_SECRET`.
- Любой, кто знает `ADMIN_SECRET`, управляет всем — не пересылайте его в чатах.
- `data.json` — простой файл; делайте регулярные копии. Для большого числа пользователей
  позже стоит перейти на PostgreSQL.
